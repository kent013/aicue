# 02. システム全体像

本システムは **PC システム（Web サイト）** と **スマートフォンアプリ** の 2 つで構成され、サーバーを介して連携する。

## 2.1 役割分担

```
┌─────────────────────────┐        ┌─────────────────────────┐
│         PC システム          │        │      スマホアプリ            │
│  （企画・編集・管理の拠点）      │        │   （現場での撮影ツール）        │
├─────────────────────────┤        ├─────────────────────────┤
│ ・手順書の登録              │        │ ・シナリオの受信/選択         │
│ ・AI によるシナリオ自動生成    │◀─────▶│ ・ナビゲーション撮影          │
│ ・シナリオ編集（手順/急所/     │  サー   │ ・複数テイクの撮影・管理       │
│   ナレーション/字幕/撮影方法）  │  バー   │ ・テイクの選択・コメント       │
│ ・テイクの選択/差し替え        │  同期   │ ・全体プレビュー             │
│ ・完成動画のプレビュー/DL      │        │ ・撮影データのアップロード      │
│ ・ユーザー/カテゴリ管理        │        │                          │
└─────────────────────────┘        └─────────────────────────┘
```

| | PC システム | スマホアプリ |
| :-- | :-- | :-- |
| 主な利用者 | 管理者・編集担当（企画側） | 現場作業者（撮影側） |
| 主目的 | シナリオを作り、素材を組み立て、動画を完成・配信する | シナリオの指示どおりに撮影素材を集める |
| 認証 | PC・アプリ共通の ID / パスワード | 同左 |

## 2.2 制作フロー（エンドツーエンド）

```
① 手順書アップロード（PC）
      │  Excel / PDF の SOP を選択
      ▼
② AI 解析（PC）
      │  手順書を構造化 → 作業分解 → シナリオ生成
      │  ※詳細は 03_AI解析とシナリオ生成.md
      ▼
③ シナリオ編集（PC）
      │  手順/急所の追加・削除・並べ替え、
      │  ナレーション/字幕/撮影方法の手直し
      ▼
④ ナビ撮影（スマホ）
      │  シナリオを受信 → カットごとに撮影指示を見ながら撮影
      │  1 カットに複数テイクを撮り、採用候補を選ぶ
      ▼
⑤ アップロード / テイク採用（スマホ→PC）
      │  新規撮影テイクをサーバーへ送信
      │  PC 側で各カットの採用テイクを確定
      ▼
⑥ 自動合成・完成（PC）
      │  採用テイク＋ナレーション＋字幕を自動合成
      ▼
⑦ プレビュー / ダウンロード / 多言語展開（PC）
         mp4 で出力。言語切替に対応
```

### プレビューの特徴

- 撮影テイクが未登録でも、**字幕とナレーションのみが付いた状態でプレビュー再生**できる（シナリオ段階での確認が可能）。
- 各カットの尺は「ナレーションの尺」と「素材の尺」を比較して自動決定される。静止画カットは表示秒数を指定でき、ナレーション尺より短い場合はナレーション尺が優先。

## 2.3 テイクとカットの関係（連携の核）

- 1 つの **カット（手順/急所）** に対して、スマホで複数の **テイク** を撮影できる。
- スマホ側ではテイクを撮影順にスタックし、**ドラッグ＆ドロップで並べ替え**、一番左（先頭）を採用候補とする。
- **同期ルール**:
  - シナリオ詳細を開いたとき、既にサーバーで採用済みのテイクがあれば端末へ**自動ダウンロード**される。
  - アップロード時は、**その端末で新しく撮影したテイクのみ**を送信し、ダウンロード済みテイクは対象外（重複送信の防止）。
  - ダウンロードしてきたテイクは端末上で削除できない。
- PC 側では、各カットに登録された複数テイクから採用テイクを選択（青枠で表示）、または PC ローカルの動画をアップロードして差し替えられる。

## 2.4 データモデル（主要エンティティ）

PC サイト Excel の「概要設計書（データモデル定義）」に基づく。

### ユーザー
`ユーザーID`（半角英数 1〜20 字, ユニーク）/ `パスワード`（8〜64 字）/ `表示名`（1〜50 字）/ `メールアドレス`（任意, 形式チェック）/ `所属ID` / `権限`（管理者・一般利用者）/ `作成日時` / `最終ログイン日時`

### 動画マニュアル
`動画マニュアルID` / `動画タイトル`（1〜200 字）/ `カテゴリID` / `作成者ID` / `作成日時` / `更新日時` / `動画の尺`（自動計算）/ `手順数` / `状態`（撮影完了・着手中・未着手）/ `公開範囲`（作成者のみ・同じ所属・全ユーザー）/ `登録データ容量`

### カテゴリ
`カテゴリID` / `カテゴリ名`（1〜50 字, ユニーク）/ `表示順`（D&D で変更）/ `作成日時` / `更新日時` / `含まれる動画数`（削除時、所属動画は「未分類」へ）

### 手順（カット）
`手順ID` / `動画マニュアルID` / `手順番号`（並べ替えで変動）/ `手順名`（1〜200 字）/ `カット種別`（**手順 / 急所**）/ `ナレーション（日本語）`（1〜200 字）/ `字幕（日本語）`（1〜100 字）/ `撮影方法`（1〜200 字）/ `素材登録状況`（未登録・動画登録済・静止画登録済）/ `素材種別`（動画・静止画）/ `登録素材ファイルパス` / `素材尺（実測）` / `静止画表示時間` / `カット尺（最終決定）` / `ナレーション（多言語, JSON）` / `字幕（多言語, JSON）`
※多言語は自動翻訳を初期値とし、手動修正・保存が可能。

### 所属
`所属ID` / `所属名`（1〜100 字, ユニーク）/ `作成日時` / `更新日時`

### ローカル撮影データ（アプリ固有）
`ローカルデータID`（端末内ユニーク）/ `紐づく動画マニュアルID` / `紐づくカットナンバー` / `ファイルパス（端末内）` / `素材種別`（動画・静止画）

## 2.5 多言語・権限

- **多言語**: 字幕・ナレーションを言語ごとに保持（自動翻訳が初期値）。プレビュー/ダウンロード時に言語を切り替え。ISO 言語コードで国際化に対応。
- **権限**: 管理者と一般利用者を分離。管理者のみ「カテゴリ管理」「ユーザー管理」メニューが表示される。動画には公開範囲（作成者のみ/同一所属/全ユーザー）を設定可能。
