`doc/01`〜`doc/10` の設計はこれらの一次資料を distill したもの。実装時の参照用に git 管理下へ移動した（`tmp/` は git 管理外のため）。

| `mockups/` | UI モックアップ画像（PC 管理/動画メニュー・SP アプリ・画面バリエーション） | [doc/04](../04_PCサイト機能仕様.md)・[doc/05](../05_スマホアプリ機能仕様.md) |
| `verification/` | AI モデル検証（2026-03-06）: 手順書構造化 unified JSON（claude/openai/gemini/yomitoku）＋生成シナリオ（v1/v2） | [doc/03](../03_AI解析とシナリオ生成.md) |
| `scenarios/` | 人手作成の参照シナリオ（拘束板QR名盤交換・玉掛用具割れ確認）＋「動画の構図のパターン例」 | [doc/06](../06_撮影シナリオの設計思想.md) |
| `sample-sop/` | サンプル作業手順書（AP/AT/AW/AS 手順書 PDF・作業要領書）＝AI パイプラインのテスト入力 | [doc/03](../03_AI解析とシナリオ生成.md) |

> **100MB 超で git 管理外にした大容量アセット**（GitHub の 100MB 制限超のため `tmp/large-assets/` にローカル退避）:
> - `動画アプリ画面作成.fig`（104MB, Figma）… 正本は Figma クラウド。git 版管理が必要なら Git LFS を導入。
> - `toyometal_sop.xlsx`（114MB, 東洋金属 SOP 原本。画像埋め込みで肥大）… テスト入力には軽量版を別途用意予定。
> どうしても git で版管理したい場合は Git LFS 導入後にこれらを LFS 追跡で追加する。
| `prompts/` | 作業分解・シナリオ生成プロンプトの原本 docx | [doc/03](../03_AI解析とシナリオ生成.md)・[doc/10 §10.4](../10_実装仕様.md) |
| `specs/` | 機能仕様 xlsx（PC サイト・スマホアプリ：ユースケース/機能一覧/構成要素/エンティティ定義） | [doc/04](../04_PCサイト機能仕様.md)・[doc/05](../05_スマホアプリ機能仕様.md) |
