# 動画マニュアル作成支援システム ドキュメント

作業手順書（SOP）から動画マニュアルのシナリオを AI が自動生成し、その指示に従って現場でスマートフォン撮影を行うことで、専門知識ゼロでも高品質なマニュアル動画を作成できるようにするシステムです。

本ディレクトリは、これまで `tmp/` 以下に蓄積してきた検討資料（提案書・ページ構成・プロンプト・AI 検証結果・モックアップ・競合考察など）を読み解き、プロジェクト全体を整理・統合したものです。

## コンセプト

> **「思考ゼロ・編集ゼロ」で、現場の知恵を資産に変える。**

作りたくても作れなかった動画マニュアルを、次の 3 ステップだけで完成させます。

1. **手順書アップロード** — 既存の Excel / PDF 手順書を登録する
2. **AI 解析** — AI が手順・急所・ナレーション・字幕・撮影方法を含む「動画シナリオ」を自動生成する
3. **ナビ撮影** — スマホアプリの指示どおりに撮るだけ。ナレーション・字幕は自動合成され、編集不要で完成する

## 用語

| 用語 | 意味 |
| :-- | :-- |
| **手順書 / SOP** | 現場に既にある標準作業手順書（Excel / PDF / 紙）。本システムの入力。 |
| **作業分解表** | 手順書を「1 動作 1 行」に解体し、手順と急所を分離した中間表。 |
| **シナリオ** | 作業分解表を撮影用に展開したもの。カット単位で映像・撮影方法・ナレーション・字幕を定義する。 |
| **手順 / 急所** | 手順＝物理的な動作。急所＝その動作の判断基準・数値・注意点（ヨリで見せる要点）。 |
| **カット** | シナリオの 1 行 ＝ 動画の 1 場面。 |
| **テイク** | 1 カットに対して撮影した個々の録画データ。1 カットに複数テイクを保持し、採用テイクを選ぶ。 |
| **ヨリ / ヒキ** | ヨリ＝寄りの接写（急所向け）。ヒキ＝引きの全体像（手順向け）。 |
