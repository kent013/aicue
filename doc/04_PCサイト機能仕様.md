# 04. PC サイト機能仕様

出典: `動画マニュアル作成支援システム_PCサイト_2.xlsx`（ユースケース / 機能一覧 / 構成要素 / エンティティ定義 / 概要設計書）、モックアップ `モック/動画アプリ/PC_動画メニュー`・`PC_管理メニュー`。

PC サイトは動画マニュアルの **企画・編集・管理** の拠点。一般利用者向けの「動画メニュー」と、管理者専用の「管理メニュー（ユーザー/カテゴリ管理）」がある。

## 4.1 画面一覧と遷移

```
ログイン画面 ──（一般）──▶ 動画一覧ページ ──▶ 新規動画作成画面 ──▶ 動画シナリオ画面 ⇄ シナリオ編集画面
      │                        │                                        │
      │                        └──▶ 動画プレビュー / ダウンロード          └──▶ テイクのプレビュー/選択画面
      │
      └──（admin）──▶ ユーザー管理画面 / カテゴリ管理画面
（パスワード再設定画面：ログインから分岐）
```

## 4.2 主要画面と機能

### ログイン / パスワード再設定
- ユーザー ID・パスワードでログイン。`admin` でログインすると管理画面（ユーザー管理）へ遷移。
- パスワード再設定: メールアドレスに再設定 URL を送信 → 新パスワードを登録。
- 異常系: ID/PW 不一致、空値、再設定リンクの有効期限切れ、パスワード文字要件違反 等でエラー表示。

### 動画一覧ページ（ホーム）
- 動画リスト（No / 状態 / タイトル / カテゴリ / 再生時間 / 更新日 / DL / 削除）を表示。
- **絞り込み**: カテゴリ / 「自分が作成したタイトルのみ」/ 状態（作成済・作成中・未着手）。
- **検索**: タイトル・作成者名などのキーワード。**並べ替え**: 更新日・タイトルで昇順/降順。
- **操作**: プレビュー（オーバーレイ、再生/停止/音量/言語切替）、ダウンロード（言語選択して mp4）、削除（確認ダイアログ）、新規動画作成、編集画面遷移、ページネーション。
- 管理者ログイン時のみサイドバーに「カテゴリ管理」「ユーザー管理」を表示。ユーザー名メニューからログアウト。

### 新規動画作成画面
- 動画タイトル・カテゴリを入力。
- **ファイル解析**: PC 上の手順書ファイルを選択して「書類解析」→ AI 解析（「解析中…」表示）→ 生成されたシナリオ画面へ。
- **自作シナリオ**: ファイルを選ばず「作成する」→ 空のシナリオ編集画面へ。
- 異常系: タイトル文字数超過/空値、非対応ファイル形式、ファイル内容不備、サイズ超過、解析タイムアウト等でエラー。

### 動画シナリオ画面 / シナリオ編集画面
- **シナリオテーブル**（手順 / 急所 / ナレーション / 字幕 / 撮影方法 / 動画）を表示・編集。
- **手順操作**: 「＋」「－」で行の追加・削除、ドラッグ＆ドロップで並べ替え。手順行を削除すると付随する急所行も同時に削除される（手順と急所の親子関係を保持）。
- **文字情報編集**: 各セル（手順/急所/ナレーション/字幕/撮影方法）を変更・追加・削除。文字数超過はエラー。
- **Undo / Redo**: 「一つ戻る」「一つ進む」で直前操作の取消・やり直し。
- **保存/破棄**: 「更新する」で上書き保存。未保存で離脱しようとすると破棄警告ダイアログ（OK＝離脱 / キャンセル＝留まる）。「別名保存」で新タイトル・カテゴリの別動画として複製。
- **プレビュー**: テイク未登録でも字幕・ナレーション付きで再生。mp4 ダウンロード可。
- **多言語**: 言語選択で外国語のナレーション/字幕原稿を表示・手動編集、当該言語の mp4 を DL。
- **動画列**: 登録済みテイクはサムネイル表示（ホバーで自動再生）。サムネイルまたは「ファイルの選択」からテイク選択画面へ。

### テイクのプレビュー / 選択画面
- テイク一覧から選んで中央プレビューで再生確認。
- **採用**: 「このテイクを採用する」で当該カットのテイクを確定（採用テイクは青枠）。
- **表示制御**: プレビューにナレーション/字幕を ON/OFF（初期は両方オフ）。
- **アップロード**: PC ローカル動画を追加（尺は 1 分まで。超過はエラー。エンコード中は「処理中」表示で採用不可）。
- **削除**: 各テイクのゴミ箱アイコン → 確認ダイアログ（OK で完全消去、復元不可）。

### ユーザー管理画面（管理者）
- ユーザー一覧表示、新規登録、編集、削除（確認ダイアログ）。
- 入力制約: ユーザー ID = 英数字 20 字以内・重複不可、表示名 = 全角 20 字以内、パスワード = 半角英数 8〜16 字、メール = 形式チェック。違反・空値・重複はエラー。

### カテゴリ管理画面（管理者）
- カテゴリ一覧表示、新規登録、名称編集、削除、並べ替え（▲▼）。
- 制約: カテゴリ名 20 字以内・同名不可・空値不可。削除するとそのカテゴリの動画は「未分類」になる。並び順は動画一覧のカテゴリ表示に反映。
