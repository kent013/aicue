# 01. プロジェクト概要と競合比較

## 1.1 背景 — なぜ動画マニュアル化が進まないのか

動画マニュアルは有効性が認識されつつも、現場での内製が進まない。原因は次の 3 つのハードルにある（提案書より）。

| ハードル | 内容 |
| :-- | :-- |
| **台本作成の難しさ** | 手順書から動画向けの台本（シナリオ）を起こすのは時間のかかる専門作業。 |
| **撮影の難しさ** | プロのカメラマン・機材がないと高品質な映像は撮れない。何をどう撮るか判断できない。 |
| **編集の手間** | 多数のカットの組み合わせ、ナレーション・字幕の付与に膨大な工数がかかる。 |

結果として「作りたいが作れない」が顧客の共通課題になっている。

## 1.2 提供価値 — 「思考ゼロ・編集ゼロ」

> **概念的位置づけ**: 本システムの本質は、熟練者の**暗黙知（現場の作業ノウハウ）を動画マニュアルという形式知へ変換する**装置である。これは知識創造理論（SECIモデル：共同化→表出化→連結化→内面化）の実装にあたる〔知識創造企業 p.12, p.83〕。tebiki が OJT（＝共同化）を起点にするのに対し、本システムは**既にある形式知＝標準作業手順書を起点に表出化・連結化を強化する**。詳細な裏付けは [07_知見の理論的裏付け](07_知見の理論的裏付け.md) を参照。

本システムは、この 3 つのハードルをそれぞれ AI とアプリで肩代わりする。

- **台本 → AI 解析**: 既存の Excel/PDF 手順書から、手順・急所・ナレーション・字幕・撮影方法を含むシナリオを自動生成。
- **撮影 → スマホナビ撮影**: 「どこに立ち」「何を」「どう撮るか」をアプリが指示。誰でもプロのように撮れる。
- **編集 → 自動合成**: 撮影した映像にナレーション・字幕が自動で合成され、編集という概念自体を不要にする。

### 導入メリット（ROI）

| 効果 | 内容 |
| :-- | :-- |
| 制作時間の短縮 | 台本・撮影・編集の各工程を大幅に短縮。 |
| 属人化の解消 | 特定の人に依存せず、誰でも同じクオリティで作成できる。 |
| 教育コストの低減 | 動画作成スキルへの依存がなくなり、研修コストを削減。 |

## 1.3 競合考察 — tebiki との思想比較（最重要）

競合 **tebiki** は「OJT を軸とした動画マニュアル・教育プラットフォーム」。撮影を起点に AI が編集し、教育・スキル管理まで一気通貫で支援する。本システム（社内呼称 **AI-CUE**）は、この tebiki との**思想の違い**を差別化の核に据える。

### tebiki の評価

- **良い点**: 動画制作が早い / AI 編集（字幕・翻訳）/ 多言語翻訳 / 教育・スキル管理まで一気通貫。
- **気になった点**:
  - **撮影品質への依存** — 動画の品質が撮影環境・機材に左右される。
  - **教える人への依存** — 教える人のスキル・説明力に内容が左右される。
  - **標準化との関係** — 現場ごとの違いや個人の教え方が残り、標準化が進みにくい。

### 起点の違い

| 観点 | tebiki | 本システム（AI-CUE） |
| :-- | :-- | :-- |
| **起点** | OJT（教える様子を撮る） | **標準作業（SOP）** |
| **AI の役割** | 撮影後の編集支援 | **撮影前の教材設計** |
| **撮影** | 教える様子をそのまま記録 | AI の**撮影指示**に従って撮る |
| **目的** | OJT の形式化（映像化） | **標準教材化** |

> **差別化の要点**: tebiki は「現場の教え方をそのまま映像に固める」アプローチ。本システムは「標準作業手順書を起点に、AI が撮るべきカットを設計し、撮影を指示する」アプローチ。撮影者・教える人のスキルに品質が依存せず、**標準化された教材**として動画を生み出せる点が本質的な違い。

> **「AIが教材設計する」の理論的裏付け**: この差別化点は教育設計論で支えられる。インストラクショナルデザイン（ID）は学習目標・教育内容・評価方法の3要素を整合させるプロセス〔研修設計マニュアル p.297〕、成人学習（アンドラゴジー）は学習者の経験を資源とし問題解決を目的とする〔同 p.166-167〕。現場の成人作業者を対象に「何を・どうする」を過不足なく提示する設計思想は、シナリオ生成プロンプトのルールと整合する（[07章](07_知見の理論的裏付け.md#72-aiが教材設計するの裏付けインストラクショナルデザインと成人学習)）。

### 本システムに必要な機能（tebiki 考察からの示唆）

標準作業 → AI が教材設計 → 撮影指示 → 動画生成 → 動画配信 というフローを実現するため、以下が必須機能となる。

- 手順書読み込み
- AI シナリオ作成
- 簡易入力（生成結果の手直し）
- 撮影ガイド（ナビ撮影）
- 自動編集（合成）

## 1.4 サービス名称案

`サービス名称の検討.pptx` で挙がっている候補。社内では **AI-CUE**（キュー＝映像の合図・準備）を軸に検討しつつ、対外提案では **VM Director** を仮称として使用している。

| 系統 | 候補 |

| MetaMovics 系 | MetaMovics Plus / Q / アドバンス / ネクスト |
| VM 系 | **VM Director（仮）** / VM ライター / VM ナビ / VM ラボ / VM 工房 / VM-Easy |
