# 06. 撮影シナリオの設計思想

本システムの価値の源泉は「AI が撮るべきカットを設計する」点にある。その設計の下敷きとなる撮影ノウハウ（＝AI に学習・再現させたい「撮影の考え方」）を整理する。

出典: `drive-download.../対象作業の分析/`（`動画の構図のパターン例.docx`、人手作成の参照シナリオ `撮影シナリオ _QR名盤交換.xlsx`・`玉掛用具割れ確認/撮影シナリオ.xlsx`）。

## 6.1 動画の構図パターン（基本原則）

作業を映像化するとき、1 手順を最大 3 種類の構図の組み合わせで見せる。

| 構図 | 内容 | 対応（ヨリ/ヒキ） |
| :-- | :-- | :-- |
| **① 全体構図** | 対象物と作業者の全体が確認できる構図で、どう動作したか | ヒキ |
| **② 位置関係構図** | 作業者の動かした身体部位と対象物の位置関係（道具を持つ手のアップ） | ヨリ（中間） |
| **③ 局部構図** | 対象物に対する動作・変化の局部（道具の先端で材料を変形させるドアップ） | ヨリ（接写） |

**組み合わせの間引きルール**:
- 作業場所・作業者と対象物の位置関係に**変化がなければ ①は不要**。
- 道具・対象物に**変化がなければ ②は不要**。
- → 手順の「変化の内容」に応じて必要な構図だけを選ぶ。これがカット数（ノード）の設計に直結する。

**作業の入り口で伝えるべきこと**:
- 特別な服装・保護具が必要なら作業前に伝える。
- 必要な道具は作業前に伝える。
- 作業開始時は、設備と作業者の位置関係がわかる構図で見せる（例: 工作機械・作業台）。作業環境がある場合は、その環境での作業者のあり方を伝える（例: 調理場・塗装室）。
- 変化を加えたら、変化後の状態を確認できるように見せる。

## 6.2 「撮影の考え方」— 参照シナリオに学ぶ

人手作成の参照シナリオ（例: 拘束板 QR 名盤交換）は、映像・撮影・ナレーションに加えて **「撮影の考え方」列** を持つ。これは「なぜそのカットを、その構図で撮るのか」という**意図**を言語化したもので、AI シナリオ生成が目指す品質の基準になる。

実例（拘束板 QR 名盤交換 / QR 名盤交換作業より）:

| 手順・急所 | 撮影 | 撮影の考え方（意図） |
| :-- | :-- | :-- |
| QR 名盤の角を曲げる | エンドニッパーを手に持つ（ヨリ） | エンドニッパーであることを理解させる |
| 〃 | 拘束板全体でニッパーを名盤に寄せる（ヒキ） | 拘束板全体における作業箇所を理解しやすくする |
| 〃 | 名盤の隅をつかんで曲げる（アップ） | 道具のどの部位で、名盤のどの位置を、どう曲げるかを見せる |
| リベットを浮かす | ドライバー・ハンマー・名盤が入った構図 | 3 者の位置関係が理解できる構図 |
| 〃 | 名盤が浮き上がる様子（アップ） | どのように浮き上がるかを見せる |

→ 同じ 1 手順でも「道具の同定 → 作業箇所の位置づけ → 局部の動作」と、**理解の段階に沿って構図を切り替える**。これが 6.1 の①②③パターンの実践。

参照シナリオは作業を段階で分けて構成している（QR 名盤交換の例）:
- **B① 作業概要** — 対象物（拘束板・QR 名盤）が何か、作業の全体像を見せる。
- **B② 作業準備** — 服装・保護具の装着、物品受け取り、工具準備、移動、品番照合。
- **B③ 交換作業** — 本作業を手順ごとに①②③構図で分解。

## 6.3 AI プロンプトへの反映

この設計思想は [03_AI解析とシナリオ生成.md](03_AI解析とシナリオ生成.md) のプロンプトに次のように落とし込まれている。

| 設計思想 | プロンプトでの実装 |

| 手順は全体像、急所は要点 | 手順＝ヒキ、急所＝ヨリを原則化 |
| 局部を射抜く構図 | 「撮影のポイント」で「ドアップで」「真横から」等を具体指示 |

| 音声なしでも伝わる | 字幕②（完全情報）を言い切り型で生成 |

## 6.4 映像文法による補強（カットのつなぎ方）

構図（①②③）が「各カットで何を見せるか」なら、映像文法は「カット同士をどう繋ぐか」を扱う。詳細・出典は [07章 7.6](07_知見の理論的裏付け.md#76-映像文法カットシーン構成)。

- **イマジナリーライン（想定線）**: 被写体を結ぶ仮想線を越えると左右の位置関係が逆転し違和感を生む〔動画制作の教科書 p.68 / 動画編集の教科書 p.66〕。作業者と設備・対象物の位置関係を保つため、ヒキ→ヨリと構図を切り替えても左右関係を一貫させる。
- **カットつなぎの型**: マニュアル動画は「原因→結果（状況説明から入る）」型が基本〔動画編集の教科書 p.42〕。手順（ヒキで状況）→急所（ヨリで要点）の流れはこの型に一致する。
- **同一動作を複数カットで見せるとき**: 30度ルール／20%ルールを意識し、同ポジション・同サイズのつなぎ（ジャンプカット）を避ける〔動画制作の教科書 p.132〕。
- **撮影の安定（スマホ前提）**: グリッド線で水平垂直を保つ〔スマートフォングラフィ p.15,17〕。脇を締める・三脚やジンバル・移動台で手ブレを抑える〔動画制作の教科書 p.42-43 / スマートフォングラフィ p.126-127〕。→ アプリの撮影ガイドの標準アドバイスに組み込める。

## 6.5 今後の検討

- 「撮影の考え方」列そのものを AI に生成させ、撮影者への教育的補足として提示するか。
- 構図の間引きルール（①②③の要否判定）を、手順の「変化の種類」からどこまで自動判定できるか。
- 参照シナリオ（人手作成の Gold データ）を評価データセットとして蓄積し、AI 生成シナリオの品質評価に用いる。
