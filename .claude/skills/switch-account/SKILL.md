# Claude アカウント切替

`claude-account` コマンドでログインアカウントを切り替える(または現状を確認する)。

## 手順

1. コマンドを解決する。`command -v claude-account` で見つからなければ
   `./scripts/claude-account`(リポジトリ内)を使う。どちらもなければ
   「このマシンには claude-account が入っていない」と伝えて終了。
2. `claude-account list` で保存済みプロファイルと現在のアカウント(`*` 印)を確認する。
3. 依頼・引数から対象プロファイルを特定する。名前・メールアドレス・プラン
   (team / max など)との部分一致でよい。候補が複数あって一意に絞れない場合は
   list の結果を見せてユーザーに選んでもらう。
4. `claude-account switch <プロファイル名>` を実行する。
   **必ずプロファイル名を明示すること**(引数なしだと対話ピッカーになり、
   非TTYでは使えない)。
5. `claude-account current` で結果を確認し、切り替わったアカウント
   (メールアドレスとプラン)を報告する。

## 注意

- 切替はマシングローバル。新しいセッションは即座に、実行中のセッションも
  トークン更新のタイミングで新アカウントに切り替わる。statusline の表示も追随する。
- 切替時に現アカウントのトークンは自動で再スナップショットされるので、
  切替前の save は不要。
- 単に「今どのアカウント?」と聞かれたら `claude-account current` だけ実行して報告する。
