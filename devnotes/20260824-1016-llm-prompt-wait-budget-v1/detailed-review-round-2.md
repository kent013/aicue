## 施策2: REQUEST_CHANGES

[Warning] 提示コードの空コンストラクタがPintのフォーマットに適合しません。

```php
private function __construct() {}
```

PSR-12系のPintでは、メソッドの開始波括弧は次行へ置かれるため、提示どおり実装すると `vendor/bin/pint --test` が赤になる可能性が高いです。

修正案:

```php
private function __construct()
{
}
```

`Throwable` の分類限界、公開面、null安全性、単一判定への集約は修正後の内容で問題ありません。
