# 対応マトリクス: design-review Round 3 (全体判定 APPROVED)

Round 3 は APPROVED。残った指摘 (承認を妨げないもの) はすべて設計へ反映した。

## [Warning] 施策 3 差し替えの失敗経路が「2 本目の置換」以外未定義

- 判断: 対応する
- 対応内容: 失敗した場所ごとの後始末と終了コードを表にした
  (一時ファイル / 控えの複製の失敗 → best-effort で消して 2、1 本目の置換失敗 → 同上、
  2 本目の置換失敗 → 控えから復元して 2、復元失敗 → 何も消さず全パスを標準エラーへ 2、
  控えの削除だけ失敗 → 生成の成功は取り消さず残存パスを明示して 2)。
  自己テストに**1 本目の置換失敗**を独立ケースとして追加した。
