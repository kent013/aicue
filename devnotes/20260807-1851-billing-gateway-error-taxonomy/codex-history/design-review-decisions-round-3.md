## 合議で設計が実際に変わった点

1. **`EXTERNAL_MESSAGE_MARKER` の新設** — 「ログに外部生成文字列が含まれない」という
   negative assertion は、**fixture の message にその文字列が確かに入っている保証**が
   無ければ空虚に green になる。gate で正方向を保証する形にした。
2. **gate のメソッド単位化** — ファイル内の出現回数ではなく `ReflectionMethod` の
   行範囲でメソッド本体を切り出し、宣言した回数と一致するかを検査する形へ。
   併せてファイル全体の合計も見る二重検査にした。
3. **期待値の独立宣言** — `directMap()` を dataset にすると誤分類を検出できないため、
   Unit テスト側に手書きの期待値表を置き、キー集合一致で書き忘れを検出する形にした。
4. **report 文言の完全一致検査** — 部分一致では文字列の追加を検出できない。
5. **自己検出の回避** — 旧 API 名の残存検査は gate 自身を正本として除外する。
6. **保証範囲の言い切りを弱めた** — 「アプリのどこにも残らない」→
   「本サービスが出す構造化ログと report message には残らない」。
