# 対応マトリクス: design-review Round 1

Codex 判定: CHANGES_REQUESTED (gpt-5.6-sol / high)。施策別 APPROVE 4 / REQUEST_CHANGES 7。

## [Critical] 施策 4: AC-06 の骨子では S8 以降を追加できない (D7 と矛盾)

- 判断: **対応する**
- 根拠: 指摘のとおり。全カードを `FAMILY_SURFACE_PIN` の 7 件と完全一致させると、
  正規の手続き (表 A に面を足し、表 B に 1 行、カード 1 枚) を踏んだ S8 でも落ちる。
  家系固定の本体は「**既存番号の面を付け替えない**」であって「7 枚しか置けない」ではない。
- 対応内容: pin 対象を `FAMILY_SURFACE_PIN` の id 集合で絞る形へ書き換えた。
  S8 以降の一意性・連番・表 B との一致は AC-03 / AC-05 が担う旨を明記した。

## [Critical] 施策 5: クラス定数をグローバル定数として参照しており PHP / PHPStan の双方で通らない

- 判断: **対応する**
- 根拠: 確定的な誤り。`STORY_FRONT_MATTER_MIN_TESTS` は `Undefined constant` になる。
- 対応内容: `Tests\Support\Bughunt\StoryFrontMatterPins` を `use` して
  `StoryFrontMatterPins::MIN_TESTS` / `::CORE_NEGATIVES` で参照する形へ直し、
  定数クラス側のコード (名前空間 / `declare(strict_types=1)` / `final class` /
  `public const int` / `list<string>` の phpdoc) も設計へ書き下ろした。

## [Critical] 施策 7: `kubun` の対象判定が全数対応表と一致していない (`終` の扱い)

- 判断: **対応する (I1 / I4 を正典どおりにし、除外を `外` のみに限定する)**
- 根拠: 指摘のとおり矛盾していた。正典は「対象内 (`kubun` が **外** でない) の web route は
  1 枚以上のカードに載ること」と明文で定めており、`終` は**対象内**である。
  一方 aicue の現行注釈は「区分 `終` に `story` は書けない」としていた。
  これは 1 route → 1 story のスカラー模型の制約であって、意味の判断ではない。
  `story` を撤去する本作業でその制約は消えるので、**正典に寄せるのが正しい**。
  実測で `終` の route は現在 **0 件**なので、寄せても作業は増えない (`kubun` の内訳は 通常 136 / 外 14)。
- 対応内容:
  - 除外判定を `KUBUN_NEEDS_REASON`（`外` + `終`）から **`KUBUN_OUT_OF_SCOPE`（`外` のみ）**へ限定した。
  - 全数対応表の I1 / I4 に「`終` は対象内として扱う (現在 0 件)」を明記した。
  - `reason` の要求 (`外` / `終` の両方に必要) は注釈側の既存規則なので**変えない**。

## [Critical] 施策 7: `fact in facts.screens` は複合 method route で欄判定を誤る

- 判断: **対応する**
- 根拠: 指摘が正確。生成器は「GET と非 GET を併せ持つ route」を**操作表側へ入れたうえで
  `compound` に印を付ける**実装なので、`facts.screens` と `facts.operations` は
  排他とは限らない…と読めるが、実測では `split_surface()` が `if fact.write_methods:` の
  分岐で**どちらか一方にしか入れていない**ため実際には排他である。
  しかし「排他であること」に依存した書き方は、将来 `compound` の扱いを変えた瞬間に静かに壊れる。
  加えて**欄違い判定を `other` 先行で書いていた**のは指摘のとおり誤りで、
  両集合に在る route を「欄違い」と誤表示する。
- 対応内容: 欄ごとに `(ラベル, 母集合の tuple, 割当 pool)` を明示的にループする形へ書き換え、
  実在判定の順序を `expected` → `other` → 不明へ直した。線形探索も消えた。
