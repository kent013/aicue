# 対応マトリクス: conceptual-review Round 1

## [Critical] (b) を全走査器へ文字どおり適用すると過剰 (観点 3)
- 判断: **対応する**
- 根拠: 指摘のとおり。「違反が 0 件」と「母集団が 0 件」は別物で、落とすのは後者だけである。
  また `PhpReferenceScanner` のように任意のソース 1 本を入力に取る再利用可能な検出器は、
  入力次第で 0 件になるのが正常であり、母集団の非空を主張する立場に無い。
- 対応内容: ブロック 1 の (b) を「**判定に使う母集団が空であること**を緑にしない」と書き直し、
  適用対象を「母集団の非空が不変条件である gate」に限定した。
  再利用可能な検出器 (入力を引数で受ける純関数) は適用対象外であると明記し、
  その代わり検出器を**使う側の gate** が母集団を持つことを要求する形にした。
