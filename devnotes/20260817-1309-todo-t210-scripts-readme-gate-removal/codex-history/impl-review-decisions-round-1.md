## [Warning] `BughuntInventoryToolSelfTest` の新コメントが新しい母集団定義と矛盾する

- 判断: **対応する**
- 根拠: 指摘が正しい。新しい照合の母集団は `git ls-files scripts/` であり、
  未追跡の `__pycache__` は母集団に入らない。「突合が汚れる」と書くと

- 対応内容: コメントを「scripts/ 配下に git 管理外の生成物を残さないため。
  台帳の突合は git 追跡下を数えるので母集団には入らないが、実ディレクトリと
  目視の一覧を汚す」へ直した (詳細設計の文面からの逸脱。理由は本行のとおり)。
