## 記録しておく限界 (誇張しない)

- **3' は型解決の差では赤くなっていない**。ルートの設定 (bundler) で `packages/cli` を
  読んでも、当該パッケージの候補は同一ファイル内で解決できる形 (定数の配列 /
  同ファイル内の型) なので値集合は変わらず、`./schemas.js` のような NodeNext 前提の
  取り込みも bundler 解決で通ってしまう (実測: 両方の設定で意味診断 0 件)。
  赤くなったのは**所有者の割当と直和の検査**である。したがって
  「型が `any` へ落ちて候補が静かに消える」経路そのものは**現物では観測されていない** —
  この方式は偽陰性を作らない側の予防であって、現に偽陰性が起きていたことの証拠ではない。
  gate が機械で固定しているのは「どのファイルもちょうど 1 本の program に載る」ことと
  「パッケージのファイルはそのパッケージの設定 (NodeNext) で組まれた program に載る」までである。
- **4c は「文脈ごとに別ファイルへ割る」実装への差し替えではない** (そのような経路は
  実装に存在しない)。module 範囲を落とす形で「module と実体を 1 単位として扱わない」
  向きの故障を代理させている。
- 故障注入は**赤くなることの観測**であって、テストが「その故障だけ」を捕まえることの
  証明ではない (1 つの故障で複数のテストが同時に赤くなるのは正常である)。
