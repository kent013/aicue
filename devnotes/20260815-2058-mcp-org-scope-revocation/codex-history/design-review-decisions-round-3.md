## 最終確認 (app-design スキル Phase 2-5)

- **使命への寄与**: 顧客の作業手順書と撮影素材を預かるアプリとして、
  「組織から外した」という管理操作が資格情報の実体に反映され、
  管理画面と監査で確認できることは預かりものを扱う前提条件である。全施策がこれに寄与する。
- **禁止事項**: 抵触なし。
  (1) テストなしの完了報告をしない — 全施策にテスト計画があり、
  不変条件は Architecture テストへの登録まで含めている。
  (2) PHPStan の widen / baseline 化をしない — 各施策に適合チェックあり。
  (4) `response()->json()` の直書きなし (外部応答を変えない)。
  (9) Artifact を使わない — 成果物はすべて `devnotes/` 配下のファイル。
- **コーディングルール**: `declare(strict_types=1)` / 日本語コメント / transaction は Service 内 /
  Factory 生成 / グローバル `RefreshDatabase` (個別 `DatabaseTransactions` 不使用) を
  各施策のテスト計画に明記済み。
