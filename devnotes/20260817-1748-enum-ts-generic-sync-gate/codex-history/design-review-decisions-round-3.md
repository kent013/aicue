# 対応マトリクス: design-review Round 3

## [Warning] C: P31〜P33 では引用符走査の正しさを観測できない
- 判断: 対応する
- 根拠: 指摘のとおり。値に逆斜線を置くと受理文法がその case を拒むので、
  **偶奇の判定が正しかったかを戻り値から観測できない**(別の理由の例外でも緑になる)。
  食い潰しの回帰にならない。
- 対応内容: P31〜P33 を「**メソッド本体の文字列**に逆斜線を 1 / 2 / 3 個以上置き、
  その**後ろに置いた普通の case が抽出結果に含まれること**を確かめる」形へ変更した
  (期待は例外ではなく**受理**)。見本の骨組みも設計書に書いた。
  case の値に逆斜線がある場合を拒む役割は **P13** に残し、役割を分けた。
  検査は例外クラスだけでなく期待する値集合か正確な失敗理由まで見る、と明記した。
