# 対応マトリクス: conceptual-review Round 4

## [Warning] `監視中` の判定条件が広すぎる (観点 5)
- 判断: 対応する (全面)
- 根拠: 指摘のとおり。i9 により `恒久` の登録も「条件 X が成立したら見直す」を必ず持つので、
  解消条件の有無は `監視中` と `恒久` の区別にならない。また「条件が判断できるようになる時期」から
  期限を決める規則は、その時期が根拠文書に無ければ結局は期限の発明に戻る
- 対応内容:
  - `監視中` にできるのは、根拠文書に**期限・予定時期・追跡中の事象**があり、そこから 400 日以内に
    見直す根拠を導ける場合だけ、と改めた
  - 見直し期限も**根拠文書から導ける日付**に限った
  - 解消の条件はあるが時期を導けないものは `恒久` にし、条件は `再判定の条件` へ転記する
  - 見直す意思は明確なのに期限だけ導けないものは、期限を発明せず差し戻す
  - 「解消の条件が書かれていることは `監視中` の根拠にならない」理由 (i9 との関係) を本文に明記した
