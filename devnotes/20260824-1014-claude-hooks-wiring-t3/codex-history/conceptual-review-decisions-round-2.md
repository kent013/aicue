## [Warning] i10 の decode 境界: `json_decode($json, true)` では `{}` と `[]` が区別できない
- 判断: 対応する
- 根拠: 実装上の事実として正しい (どちらも `[]` になる)。区別できないと「object でない」の負例が
  正例と同じ結果になり、負例の裏取りが形骸化する。
- 対応内容: 「連想配列へ直接 decode せず、`json_decode($json)` で受けて
  `Assert::isInstanceOf($decoded, stdClass::class)` で narrow し、`get_object_vars()` でキー集合を得る。
  JSON 構文エラー (`JsonException`) は object 不成立とは**別種の fail-closed** として扱う」を明記した。
  戻り型は `list<string>` (キー集合) に閉じ、値は照合に使わないので広げない。
