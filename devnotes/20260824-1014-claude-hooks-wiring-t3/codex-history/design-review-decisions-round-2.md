# 対応マトリクス: design-review Round 2

## S2 [Critical] S13b の行継続バックスラッシュが過剰エスケープで、狙った分岐 (0 秒等) を通らない
- 判断: 対応する
- 根拠: 指摘のとおり。二重引用符でのエスケープは曖昧で、`\\\\` が 2 文字になると kill の正準形が
  0 件になり「値が 0」の分岐へ到達しない (= `if ($value <= 0)` を消しても赤いまま)。
- 対応内容: **nowdoc で基準本文を作るヘルパ** `claudeHooksSyntheticUpdateHookBody($mutate, $replacement)`
  を新設した (nowdoc はバックスラッシュをそのまま 1 文字として入れる)。各データセットは
  `str_replace()` で**1 か所だけ**変異させ、変異元が本文に無ければ `Assert::contains()` で
  空振りを落とす。正のコントロール (S13d) にも合成の基準本文を 1 件置き、3 値がちょうど取れることと
  囮のコメント行が件数を増やさないことを固定した。

## S2 [Critical] 正準行が 1 件あれば非正準の実行行が併存しても検出できない
- 判断: 対応する
- 根拠: 指摘のとおり。正準形に一致する行を数えるだけでは併存を見逃す。
  Round 2 の説明 (「同じ語彙を持つ別行は違反」) は実装が追いついていなかった。
- 対応内容: **候補母集団の計数** `claudeHooksInnerLimitCandidateCounts()` を新設し、
  コメント行を除いた実行行のうち関連語彙を持つ行を数え、**候補数 == 正準形の一致数**を要求する。
  区切り (空白・タブ・代入の最初の `=`) を docblock で宣言し、判定はトークンの完全一致にした。
  併せて kill の正準形を**次行の更新本体まで含む複数行**にし、猶予が更新の起動へ接続していることも見る。
  負例に「正準形と非正準の併存」「猶予が更新本体へ接続していない」の 2 形を追加した。

## S2 [Warning] S13b の fixture が複数箇所を同時に壊している
- 判断: 対応する
- 根拠: 分岐ごとの裏取りにならない。
- 対応内容: 上記ヘルパで**基準 1 本 + 1 か所変異**の形に統一し、指摘された 7 分岐
  (0 件 / 2 件 / 申告に無い形 / 値が 0 / 未知のスクリプト / 関係が等しい / 関係が超える) を
  それぞれ個別のデータセットにした (S13b が 8 形、S13c が 5 形)。

## S2 [Warning] S13c の closure の `array` に要素型が無い (PHPStan level 10)
- 判断: 対応する
- 根拠: iterable value type の欠落で落ちうる。
- 対応内容: dataset を `?int $stdin, ?int $body, ?int $kill, int $harness, bool $shouldFail` に分解し、
  closure 内で shape を組み立てる形にした (理由もコメントに書いた)。

## S2 [Warning] B18 の「CI の揺らぎ 5 秒」に根拠が無い
- 判断: 対応する (指摘の 2 番目の案を採る)
- 根拠: 実測分布が無いまま閾値を締めるのは思考原則に反する (「仕組みが機能していない段階で値を弄るな」)。
- 対応内容: 実測の上限を**設定由来の値** (`claudeHooksHookTimeout('PostToolUse')` = 30 秒) にした。
  stub は 120 秒眠るので、内側の時間切れが効いていなければ必ず超える。数値の**関係**は静的層 (S13) の
  担当という役割分担をコメントに明記した。

## S6 [Warning] i15 の外部仕様上の前提を再確認できる所在が無い
- 判断: 対応する (実読して記録を作った)
- 根拠: 「仕様である」と書くだけでは将来の担当者が再現できない。
- 対応内容: 実読記録 `devnotes/20260824-1014-claude-hooks-wiring-t3/code-review-graph-diff-premise.md`
  を作成し、指摘の 4 点 (差分基準 / 未索引変更の検出方法 / 除外規則 / 状態更新のタイミング) を
  実読で埋めた。**実読で前提が 1 つ狭まった** — `update` の既定は `--base HEAD~1` で
  `git diff --name-only HEAD~1 --` (1 つ前のコミットから作業ツリーまで) なので、
  **シェルで変えたファイルをコミットしたあと編集を挟まずにコミットを重ねると回収されない**。
  docblock と AGENTS.md の記述をこの範囲へ狭め、両方から記録へ辿れるようにした。
