# 対応マトリクス: conceptual-review Round 1

## [Warning] 端の前後ボタンの扱いが曖昧 (disabled にすると禁止事項 8 に抵触)

- 判断: **対応する**
- 根拠: 概念設計は「端では移動しない / 告知する」とは書いたが、
  「端でもボタンは押せる (disabled にしない)」を明文化していなかった。
  AGENTS.md 禁止事項 8 は「必須条件未充足を理由に disabled にしない」であり、
  端は典型的にその条件に当たる。明文化しないと実装者が素直に `disabled` を書く。
- 対応内容: 「操作の設計」節に **端でも前後ボタンは押下可能** であること、
  押下時に `role="status"` で「これが最初のカットです」/「これが最後のカットです」を
  出すことを明記した。スワイプ・キー操作も同じ告知経路を共有する
  (告知文の出所を 1 か所にする) と書いた。

## [Warning] 「全画面を終了」後に横持ちのまま既存レイアウトへ戻すと、横持ち 1 カラム問題が再発する

- 判断: **対応する** (指摘は正しく、しかも設計に**再入手段の欠落**という別の穴があった)
- 根拠: 元案は「一度終了したら縦に戻すまで自動で入り直さない」というラッチだけを置いていた。
  これは意思の尊重としては正しいが、**横持ちのまま全画面へ戻る明示手段が無い** =
  端末を一度縦に倒し直さないと全画面へ帰れない、という行き止まりになる。
  Codex の指摘 (終了後に何が操作可能になるのか) と合わせて、
  「終了後の面で何ができるか」+「そこから全画面へ戻れるか」の両方を受入条件にする。
- 対応内容:
  1. 既存レイアウト側に **「全画面で撮影」ボタン**を置く (横持ち判定が真のときだけ表示。
     押すとラッチを解除して全画面へ入る)。これでラッチは「自動で入らない」だけの意味になり、
     手動の再入路が常に残る。
  2. 終了直後は既存の `navigateToPanelIfNeeded` (視点とフォーカスの移送) を再利用して
     撮影パネル見出しへ運ぶ。終了で現在位置を見失わせない。
  3. 受入条件として「終了後の横持ち 1 カラムでも、録画の開始/停止・テイク操作・
     カット一覧・マニュアル詳細への復路の 4 つがすべて到達可能」を明記した。

## [Warning] `pointer: coarse` はタッチ対応ノート PC で意図せず真になりうる

- 判断: **対応する** (条件式は変えず、検査を足す)
- 根拠: タッチ対応ノート PC は `pointer: coarse` を返しうるが、
  `max-height: 540px` を同時に満たすことは実質無い (ブラウザ全画面でも縦 540px 未満は稀)。
  条件を増やすと判定が複雑になるだけで、実害の大きさに見合わない (思考原則 2)。
  ただし「壊れていないこと」を機械で固定していないのは指摘のとおり。
- 対応内容: 受入条件に **「デスクトップ横長 viewport では既存 2 カラムが維持される」**
  を Browser テスト (Chromium + WebKit 両レーン) の負のコントロールとして追加した。
  実機受入確認の列挙にもタッチ対応 PC の項を足した。

## [Suggestion] 「映像面積 2 倍前後」は端末差があるので代表 viewport の実測値に落とす

- 判断: **対応する** (概念設計では表現を弱め、実測は詳細設計へ送る)
- 根拠: 数値の根拠を持たないまま効果を主張するのは「データに真摯に向き合え」に反する。
- 対応内容: 期待効果から「実質 2 倍前後」という断定を外し、
  「代表 viewport での実測値は詳細設計で確定する」と書き換えた。

## [Suggestion] TS 側は layout 種別を union 型にする

- 判断: **対応する**
- 根拠: 既存 `CameraRecorder` の `Phase` も `type Phase = "idle" | …` の union で、
  リポジトリの先例に一致する。
- 対応内容: 実装方針の表に「レイアウト種別は string ではなく union 型
  (`"inline" | "fullscreen"`) で受ける」と明記した。

## [Suggestion] 使命整合 / 実現可能性 / スコープ / 型安全性は肯定的評価

- 判断: **見送る** (対応不要)
- 根拠: 指摘ではなく評価。設計変更を要しない。
