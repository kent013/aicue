Codex の全体判定は **CHANGES_REQUESTED**。Round 2 の 4 件のうち 3 件は解消と判定され、

## [Critical] 跡に空白を残すだけでは、最小断片が元々空白を含む位置で合成できる

- 判断: **対応する**
- 根拠: 指摘のとおりである。`` `同一<!-- 見える印 -->PR 内で` `` は読者には最小断片と違う文に
  見えるのに、跡を半角空白にすると `同一 PR 内で` になって一致してしまう。
  「跡に何かを残す」という方向は正しかったが、**残す文字が本文に書ける文字だったのが誤り**。
- 対応内容: 跡に残す目印を**垂直タブ (U+000B)** にした。要件は 2 つで、
  (1) 規範の最小断片に現れ得ない文字であること、
  (2) `trim()` が空白として落とす文字であること (落とさない U+0000 等にすると、
  コメントだけの行が「本文のある行」に見えて節の非空検査をすり抜ける)。
  垂直タブはこの 2 つを同時に満たす。
  負の fixture に「最小断片が元々空白を含む位置にコメントを置く形」を 2 例足した
  (`同一<!-- … -->PR 内で` と `DESIGN.md<!-- … --> が唯一の真実`)。

## [要修正] `docs/design-system.md` の説明が上の回避例で成立しない

- 判断: **対応する**
- 対応内容: 「空白を 1 つ残すので前後が繋がらない」を
  「本文に書けない目印を残すので、コメントを挟んだ 2 つの断片が検査の上でだけ繋がることはない」
  に直した。

## [Warning] D27 の再判定の条件に `:root, :host` の形が残っている

- 判断: **対応する**
- 根拠: コード側は「完全一致を要求しない」と決めたので、登録簿の再判定の契機に
  selector の綴りが残っていると契約が食い違って読める。
- 対応内容: D27 の再判定の条件から selector の綴りを外し、
  「selector の綴りそのものは検査の完全一致対象ではないので再判定の契機にしない」と明記した。
