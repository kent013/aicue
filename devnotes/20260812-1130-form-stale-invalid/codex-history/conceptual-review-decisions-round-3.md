# 対応マトリクス: conceptual-review Round 3

判定 CHANGES_REQUESTED。Critical 1 / Warning 2。**すべて対応**(反論なし)。

## [Critical] page props のオブジェクト同一性は、このフォームの送信と相関していない

- 判断: **対応する**
- 根拠: 妥当。Round 2 で棄却した `router.on('finish')` と**同じ欠陥を形を変えて**持ち込んでいた。
  無関係な visit / partial reload で参照が入れ替われば、請求先を再検証していないのに解除されて
  古いエラーが復活する。逆に partial reload で `errors` が応答対象外なら参照が保たれ再表示されない。
  **どちらにも倒れうる前提に不変条件を置いていた。**
- 対応内容: 解除契機を **このフォーム自身の `router.patch` の結果**へ変更した:
  入力で編集済み → **`onError` で解除** (新しい検証結果が届いた) → `onSuccess` でも初期化。
  `onFinish` 単独は使わない (キャンセル・通信失敗でも動くため)。
  並行送信に備えて**送信世代**を持ち、古い応答が新しい編集状態を解除しないようにする。
