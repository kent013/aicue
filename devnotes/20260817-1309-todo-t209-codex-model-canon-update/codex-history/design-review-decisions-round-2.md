## [Warning] 負のコントロールの検体数と実行単位が一致していない

- 判断: **対応する**
- 根拠: 指摘のとおり。1 つの `it` に複数の検体を並べると、
  未実装スタブの段 0 で最初の assert が落ちた時点で止まり、
  後続の検体が実際に赤になったことを確認できない
  (「全分岐で点灯する」という主張が実測に基づかなくなる)。
- 対応内容: 検体を一意な ID (N-01〜N-23) で**1 検体 = 1 つの `it`** に分解し、
  `it.each` で回す。段 0 と受け入れ条件 A5 の記述も「23 検体」に合わせた。
  4 件の変種 (表の行が 2 行 / 4 行、見出しが 2 つ / 0 つ、表が別の節へ移動) は
  それぞれ独立した検体 (N-19〜N-23) として並べた。

## [Warning] 層 3 の節の終端規則が未定義

- 判断: **対応する**
- 対応内容: 節の切り方を**層 2 と層 3 の共通規約**として明文化した。
  - 見出しとして数えるのは行頭が `#` の行 (ATX 見出し) である。
  - **コードフェンスの中の行は見出し・宣言として数えない**
    (スキル文書は書式の見本をフェンスで囲むため、見本を実体と取り違えない)。
    ただし**層 1 の綴りの走査はフェンスの中も見る**
    (見本の中に綴りを隠して逃げる経路を作らない)。負のコントロール N-10 で固定する。
  - 層 2 の節: 見出し行から次の見出し行の直前まで (レベルは問わない)。
  - 層 3 の節: `## 利用可能モデル` から**次のレベル 1 または 2 の見出しの直前**まで。
    `###` 以下の小見出しは節を切らない。
