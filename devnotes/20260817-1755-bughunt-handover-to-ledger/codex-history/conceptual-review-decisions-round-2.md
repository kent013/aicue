## [Warning] 「全 id が現れる」では部分文字列一致・重複・孤児を見逃す (観点 7)
- 判断: **対応する**
- 対応内容: テスト契約を集合の一致へ変えた。生成物から**見出し行の構造** (`^### (A-\d+) — `) で
  id を抽出し、registry の id 集合と (a) 欠落なし (b) 余分なし (c) 各 id ちょうど 1 回 で突き合わせる。
  本文走査をやめて見出しの構造照合にしたのは、`A-001` が `A-0010` に当たる類の
  部分一致を原理的に起こさないためである。
- supersede 表示についても後継を単数と仮定しないよう変更した。照合器は循環・自己参照・未知 id しか
  見ておらず、同じ id を supersede する登録が 2 件現れることを禁じていないため、
  「この登録を supersede している全 id」を id の昇順で並べて表示する契約にした。
